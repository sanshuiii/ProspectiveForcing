# Source provenance

Prospective Forcing builds on publicly released Rolling Forcing and Wan2.1
components. The causal-model initializer is distributed separately by the
Causal Forcing project. Public upstream links and license notes are recorded in
`THIRD_PARTY_NOTICES.md`; weights are never copied into this source package.

The release preserves the registered two-stage training and B0/A1/M1 inference
contracts while using public module names and path-neutral launchers.
