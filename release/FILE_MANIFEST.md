# Source-only release manifest

This package contains:

- two-stage Prospective Forcing training code and reference configurations;
- B0, A1, and M1 inference code and launchers;
- precomputed-text-embedding preparation tooling;
- empty, documented locations for the base, Stage 1, and Stage 2 checkpoints;
- environment, checkpoint, and release-contract validation utilities;
- upstream license and third-party notices.

The package intentionally excludes model weights, datasets, prompt corpora,
generated videos, metrics, logs, scheduler files, provenance containing machine
identity, and experiment outputs.
